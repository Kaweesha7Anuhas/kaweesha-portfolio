# Kaweesha Anuhas - Portfolio Website

A modern, production-ready personal portfolio website designed to showcase my projects, skills, and experience to recruiters and hiring managers.

![Portfolio Banner](https://kaweesha-portfolio.vercel.app/opengraph-image) <!-- This will work after Phase 12! -->

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & shadcn/ui
- **Animations:** Framer Motion
- **Forms:** React Hook Form & Zod
- **Email:** Resend
- **Icons:** Lucide React & React Icons

## ✨ Features

- 🌙 Dark/Light mode toggle (defaults to dark)
- 📱 Fully responsive mobile-first design
- 🎨 Glassmorphism UI with glowing gradient accents
- ⌨️ Typing animation for roles
- 🔍 Filterable projects grid with detailed modals
- 📅 Interactive education timeline
- 📬 Working contact form with validation and spam protection
- ⚡ Blazing fast performance and SEO optimized
